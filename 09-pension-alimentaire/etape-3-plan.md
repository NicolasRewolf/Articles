## Intro — Version D (LEARN-007/009)

*Ordre : reconnaissance psychologique → chiffre → bullets « ce que vous allez comprendre ».*

> On vous a dit de « saisir la CAF », de « porter plainte », peut-être de « prendre un avocat » — sans vraiment vous expliquer ce qui marche, ni dans quel ordre. Quand la pension n'arrive pas, ce n'est pas qu'une ligne en moins sur un relevé : pour une famille monoparentale, la pension représente en moyenne **18 % des ressources** ([CNAF, 2024](#)). Et même avec l'intermédiation automatique de l'ARIPA, **près d'un tiers des sommes dues n'est toujours pas recouvré**.
>
> Ce guide remet de l'ordre. **Ce que vous allez y trouver :**
> - comment la pension est fixée — et pourquoi le « barème » ne s'impose pas ;
> - comment la faire **réviser** quand vos revenus changent (sans tomber dans le piège de l'ARIPA) ;
> - la **chaîne complète des recours** quand elle n'est pas payée, jusqu'à l'**abandon de famille** ;
> - ce qu'un avocat pénaliste actionne que les autres laissent de côté.

**TDM** (6 ancres cliquables — LEARN-008) : Ce qu'est (et n'est pas) la pension · Comment elle est fixée · La faire réviser · Elle n'est pas payée : vos recours · L'abandon de famille · La « nouvelle loi » démêlée.

## Plan détaillé H2/H3 (budget ~2 380 mots)

### H2.1 — La pension alimentaire, en clair (et ce qu'elle n'est pas) — ~190 mots
- **Objectif** : poser la définition (front-load GEO) + lever LA confusion (enfant / époux / prestation compensatoire).
- **Contenu** : contribution à l'entretien et l'éducation (un parent → l'autre) ; ce qu'elle couvre ; **encadré disambiguation** : pension enfant (371-2/373-2-2) ≠ pension entre époux au titre du **devoir de secours** pendant la procédure (255) ≠ **prestation compensatoire** post-divorce (270, capital/rente).
- **Justification** : intent « définition » + périmètre Nicolas (enfant + époux) ; l'encadré = lien vers l'affaire prestation compensatoire (preuve).
- **Sources/liens** : 371-2, 373-2-2 ; **lien interne** affaire *prestation compensatoire* + expertise `avocat-divorce-bordeaux`.

### H2.2 — Combien ? Comment elle est fixée (et le barème qui ne s'impose pas) — ~190 mots *(court, anti-commodity)*
- **Objectif** : répondre au « combien » sans recopier le barème (commodity gov-owned).
- **Contenu** : méthode 371-2 (proportion ressources des deux parents + besoins de l'enfant) ; la **table de référence est indicative**, le JAF tranche souverainement ; **garde alternée n'exclut pas** une pension en cas de disparité de revenus (nuance). **Renvoi au simulateur officiel** (externe).
- **Justification** : capte l'intent calcul (fan-out) en restant court ; le « barème non contraignant » est une nuance peu dite (mini Information Gain).
- **Sources/liens** : 371-2 ; **lien externe** simulateur service-public/justice.fr (nofollow) ; Judilibre cible (garde alternée + pension) → Étape 4.
- **Mini-CTA #1** (post-info, double-face LEARN-031).

### H2.3 — La faire réviser : quand les revenus (ou les besoins) changent — ~250 mots
- **Objectif** : servir le débiteur de bonne foi ET le créancier (révision ↑/↓) — cœur de l'arbitrage « notion, pas plaidoirie ».
- **Contenu** : 373-2-13 (modifiable **à tout moment**, changement de circonstances) ; cas typiques (licenciement, maladie, hausse de revenus, nouveaux besoins) ; **⚠️ le piège ARIPA** (Information Gain verbatims) : tant que le JAF n'a pas révisé, l'ARIPA continue de réclamer l'ancien montant → **saisir le JAF, ne pas cesser de payer** (sinon abandon de famille).
- **Justification** : vécu récurrent des formulaires, mal couvert ailleurs ; sécurise le ton « les deux côtés ».
- **Sources/liens** : 373-2-13 ; **lien interne** expertise `droit-de-la-famille`.

### H2.4 — Elle n'est pas payée : la chaîne des recours — ~440 mots *(LE pivot — gros budget)*
- **Objectif** : la séquence complète et ordonnée que personne ne donne en entier.
- **Contenu (liste ordonnée + tableau « situation → levier »)** : 1) amiable / **mise en demeure** LRAR ; 2) **ARIPA** (automatique depuis 2023 ; recouvre auprès employeur/banque **sans huissier préalable**) + **ASF 200,78 €/mois/enfant** versée en avance puis recouvrée ; 3) **paiement direct / saisie** ; 4) seuils : **arriérés sur 5 ans** (2224), interruption par commandement/saisie. Voix « main tendue » (créancier lésé).
- **Justification** : angle mort avocat (LEARN-059) ; agrégation substitutive (LEARN-048) ; couvre non payée/recouvrement/saisie/ARIPA.
- **Sources/liens** : IFPA (CSS R582-5 s.), ASF (service-public F815), 2224 ; **liens externes** ARIPA/service-public (nofollow) ; **lien interne** `droit-de-la-famille`.
- **Mini-CTA #2**.

### H2.5 — L'arme pénale : l'abandon de famille (227-3) — ~310 mots *(pivot pénaliste)*
- **Objectif** : le levier distinctif du cabinet, expliqué par un pénaliste.
- **Contenu** : **> 2 mois** d'impayé → délit, **2 ans / 15 000 €** ; vise **aussi** le non-versement à l'ARIPA ; comment porter plainte ; **élément intentionnel** (mauvaise foi) vs **impossibilité réelle de payer** = cause d'exonération (nuance Judilibre) ; ce qu'un pénaliste actionne. **Pont** : la **non-représentation d'enfant**, pendant pénal (lien affaire).
- **Justification** : intersection pénal (#1) ∩ famille (#2) du cabinet ; Information Gain ; conversion forte.
- **Sources/liens** : 227-3 CP ; **liens internes** expertise `droit-penal` + affaire *non-représentation d'enfant* ; Judilibre cibles (intentionnalité, impossibilité) → Étape 4.
